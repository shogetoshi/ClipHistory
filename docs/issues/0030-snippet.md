- Snippet機能を同居させる。
- 本来なら全く別アプリにすべきものを一つのアプリに載せるので、相互運用などは一切考えないで良い。
- インターフェイスはクリップボード履歴と同じ
- クリップボードとは別のホットキーで起動する
- 要件
    - アイテムはプレーンテキストで管理
    - 設定で任意の複数のディレクトリを指定すると、その配下（再帰的に探索）の全ての.mdファイルを見つける
    - 例としてgit.mdの中身は下記の通り
    - `###`で始まる行から、次の`###`までの間を1アイテムとする
    - 検索対象（左側）に表示するのはファイル名（拡張子を除く）+アイテムのタイトル
        - rebase onto の場合、「git rebase onto」
    - プレビューにはこのアイテムのテキスト全体を表示
        - ###の行も含む
    - ただし、選択した場合クリップボードに入るのは、アイテムの中で最初の「```」の開閉の中のみ。
        - rebase onto の場合、対象は「git rebase --onto <ここに> <ここから> <これを>」だけ
    - 選択した後の動きはクリップボードと同様
        - Vimモードに入れるのも同様

--- git.md ここから ---
### branch rename master to main
```bash
git branch -m master main
```

### rebase onto
```bash
git rebase --onto <ここに> <ここから> <これを>
```

```
o-o-o     develop (d1,d2,d3)
   \o-o   feature (f1,f2)

git rebase --onto d1 d2 feature

o-o-o     develop (d1,d2,d3)
 \o-o     feature (f1,f2)
```

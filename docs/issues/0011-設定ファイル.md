- 設定ファイルを設ける
    - 場所はXDG Base Directoryに沿うように
    - ファイル形式はtoml
- はじめの題材として、Vim起動時の環境変数を設定できるように
    - `[nvim.env]` テーブルに書いたものを渡す
    - 値はリテラルとして渡す（シェル展開はしない）
- あわせて、このアプリからの呼び出しにだけ効くnvimの追加設定も置けるように
    - `~/.config/nvim/` は今までどおり読まれること
    - このアプリ専用の設定を `~/.config/nvim/` の中に書かせないこと
    - 走る位置が違う2段を用意する
        - 利用者設定の**前**: `init-pre.lua`
            - PATHの追加など、プラグイン・LSPの起動に間に合わせたい処理を置くため
            - `vim.env.PATH` はLuaから書き換えられ、プロセスの環境変数が実際に変わる
        - 利用者設定の**後**: `init.lua`
            - オプション・キーマップの上書きを効かせるため
    - どちらもファイルがあれば読む。無ければ何も加えない
- 設定ファイルが無くても、これまでどおり動くこと
- 外部依存を増やさないこと（design 13.1）

## 注意（実装時に踏んだ穴）

- `NVIM_APPNAME` を `[nvim.env]` に書くと、nvimが設定を読むディレクトリ自体が切り替わり
  `~/.config/nvim/` が読まれなくなる。設計書に書いてはならない旨を残すこと
- `PATH` を `[nvim.env]` に書いても `$PATH` は展開されないため、PATHがリテラル文字列に壊れる。
  PATHの追加は `init-pre.lua` で `vim.env.PATH` を使う。設計書に書き分けを残すこと
